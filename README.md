# Vaulty

Offline vault for identity documents and cards. The phone app is on the stores. Mac, Windows, and Linux builds are attached to this repo’s [releases](https://github.com/sidcasmm/Vaulty-Offline-By-Design/releases/latest).

## Phone

- **Android:** [Google Play](https://play.google.com/store/apps/details?id=com.flutteroid.vaulty.vaulty)
- **iPhone:** App Store link goes here once the listing is approved.

## Desktop

Open the [latest release](https://github.com/sidcasmm/Vaulty-Offline-By-Design/releases/latest) and download the file for your computer.

| Computer | File |
| --- | --- |
| Mac | `Vaulty-macOS.dmg` |
| Windows | `Vaulty-Windows.zip` |
| Linux | `Vaulty-Linux.tar.gz` |

On Linux, unpack the archive and run the `vaulty` program inside it. On Windows, unpack the zip and run `vaulty.exe`.

These downloads are not on the Mac App Store, the Microsoft Store, or a Linux store. macOS and Windows may warn that the app is from an unidentified developer until a signing certificate is added.

## Source

The app itself lives in [sidcasmm/Vaulty](https://github.com/sidcasmm/Vaulty). A desktop release is built from that repo with the **Desktop release** action in this one: Actions → Desktop release → Run workflow, then enter the version (for example `1.0.0`).
